# Download_Video

Chrome Extension giúp tải **video** và **hình ảnh** trên bất kỳ trang web nào: mỗi video / ảnh sẽ có một nút **Download** để tải về máy.

> **Trạng thái:** đang phân tích & thiết kế — chưa có bản cài đặt.

## Dành cho AI / DEV tiếp nhận dự án

Đọc [`GEMINI.md`](GEMINI.md) trước tiên: chứa quy tắc bắt buộc, trạng thái hiện tại, việc tiếp theo và nhật ký công việc.

## Cài đặt (sẽ cập nhật khi có bản build)

1. Mở `chrome://extensions`
2. Bật **Developer mode**
3. Bấm **Load unpacked** và chọn thư mục extension
