================================================================================
          HƯỚNG DẪN CÀI ĐẶT & SỬ DỤNG: DOWNLOAD VIDEO & IMAGE (CHROME EXTENSION)
================================================================================

Dự án: Chrome Extension tải mọi hình ảnh và video trên Internet.
Hỗ trợ mạnh mẽ: YouTube, Facebook, TikTok, Instagram (Reels & Stories), X (Twitter), Threads.
Các tính năng chính:
  - Tải ảnh gốc / ảnh nét nhất (tự trích xuất srcset, background CSS).
  - Tải video thường (.mp4, .webm) trực tiếp qua trình duyệt.
  - Nút [⬇]   : Tải video chuẩn tương thích cao (H.264 + AAC, tối đa 1080p).
  - Nút [MAX] : Tải video nét nhất có thể (2K / 4K AV1/VP9 nếu nguồn có hỗ trợ).
  - Nút [MP3] : Tải riêng âm thanh chất lượng cao 320kbps (dùng ffmpeg trích xuất).
  - Hộp thoại Save As: Chọn thư mục lưu (ổ D:, Desktop,...) và đổi tên trước khi tải.
  - Thông báo hoàn tất: Tích hợp nút "📂 Mở thư mục" để bôi đen sẵn file vừa tải.
  - Gợi ý cài VLC miễn phí nếu video 2K/4K dùng chuẩn mới (AV1/VP9).
  - PHIÊN BẢN MOBILE ANDROID (.APK): Hoạt động độc lập 100% trong điện thoại, tích hợp trình duyệt nhúng duyệt mạng xã hội và tải video/ảnh/âm thanh thẳng vào Bộ sưu tập máy.

Repository GitHub: https://github.com/adwewecat/Download_Video.git

================================================================================
                    CÁC BƯỚC CÀI ĐẶT (KỂ CẢ KHI CÀI LẠI WINDOWS)
================================================================================

Bạn chỉ cần thực hiện đúng 3 bước cực kỳ đơn giản sau (mất khoảng 1 - 2 phút):

--------------------------------------------------------------------------------
BƯỚC 1: LẤY MÃ NGUỒN DỰ ÁN VỀ MÁY
--------------------------------------------------------------------------------
Cách 1 (Khuyên dùng nếu có Git):
  - Mở PowerShell hoặc Git Bash, gõ lệnh:
      git clone https://github.com/adwewecat/Download_Video.git
      cd Download_Video

Cách 2 (Tải trực tiếp từ trình duyệt):
  - Truy cập: https://github.com/adwewecat/Download_Video
  - Bấm nút màu xanh "Code" -> chọn "Download ZIP".
  - Giải nén file ZIP vào một thư mục cố định trên máy (ví dụ: D:\LAPTRINH\Download_Video).

--------------------------------------------------------------------------------
BƯỚC 2: CÀI ĐẶT TRÌNH HỖ TRỢ TRÊN MÁY (NATIVE HELPER) - CHỈ CẦN CHẠY 1 LẦN
--------------------------------------------------------------------------------
  1. Mở thư mục dự án trên máy.
  2. Vào thư mục: native-host
  3. Nhấp đúp chuột vào file: setup.bat

  * File setup.bat sẽ tự động thực hiện toàn bộ:
      + Tải công cụ yt-dlp.exe (trích xuất video).
      + Tải bộ giải mã ffmpeg.exe & ffprobe.exe (ghép video & âm thanh chất lượng cao).
      + Tải deno.exe (hỗ trợ giải mã thuật toán YouTube mới nhất).
      + Sinh file manifest cấu hình host với Extension ID chuẩn.
      + Đăng ký Native Messaging Host vào Windows Registry (HKCU - không cần quyền Admin).
  * Chờ màn hình hiển thị: "=== CAI DAT HOAN TAT THANH CONG! ===" là xong.

--------------------------------------------------------------------------------
BƯỚC 3: NẠP TIỆN ÍCH VÀO GOOGLE CHROME
--------------------------------------------------------------------------------
  1. Mở trình duyệt Google Chrome.
  2. Truy cập vào thanh địa chỉ:
      chrome://extensions/
  3. Ở góc trên bên phải màn hình, BẬT công tắc: "Developer mode" (Chế độ cho nhà phát triển).
  4. Ở góc trên bên trái màn hình, bấm nút: "Load unpacked" (Tải tiện ích đã giải nén).
  5. Chọn thư mục "extension" nằm bên trong thư mục dự án này.
  6. Xong! Bạn sẽ thấy biểu tượng tiện ích "Download Video & Image" xuất hiện trên Chrome.

================================================================================
                              HƯỚNG DẪN SỬ DỤNG
================================================================================

1. Vào bất kỳ trang web nào (YouTube, Facebook, Instagram, TikTok, X, báo mạng,...).
2. Rê chuột lên bức ảnh hoặc video bất kỳ (có kích thước tối thiểu 60x60 px):
   - Một thanh công cụ nhỏ màu xanh sẽ nổi lên ở góc trên bên phải của media.
3. Bấm vào nút bạn muốn tải:
   - Với ảnh: Bấm nút [⬇] để tải về bản nét nhất.
   - Với video mạng xã hội:
       + Bấm [⬇]   : Tải bản MP4 tương thích cao (chuẩn H.264 mở được trên mọi máy).
       + Bấm [MAX] : Tải bản nét nhất (2K / 4K).
       + Bấm [MP3] : Tải riêng bản nhạc / âm thanh MP3 chất lượng cao 320kbps.
4. Hộp thoại "Save As" của Windows sẽ hiện lên:
   - Tự động ghi nhớ thư mục bạn đã chọn trước đó (ví dụ ổ D:\Videos), không bắt bạn phải duyệt lại folder mỗi lần tải.
   - Tự động điền sẵn tên video kèm dấu thời gian chính xác tới mili-giây (VD: TênVideo_20261108191301443.mp4) giúp không bao giờ bị trùng tên hoặc bị hỏi ghi đè.
   - Có thể đổi tên file theo ý muốn rồi bấm Save / Enter (hoặc bấm Cancel nếu muốn huỷ).
   - TẢI NHANH 1-CLICK: Giữ phím Shift khi bấm nút tải (⬇ / MAX / MP3) để lưu thẳng vào thư mục đã nhớ mà không cần mở hộp thoại Save As!
5. Khi tải xong:
   - Chrome hiện thông báo ở góc màn hình.
   - Bấm nút "📂 Mở thư mục" để File Explorer mở ngay thư mục và bôi đen file vừa tải.

================================================================================
                     HƯỚNG DẪN KHI CẬP NHẬT HOẶC SỬA LỖI
================================================================================

Mỗi khi bạn kéo code mới từ GitHub về hoặc chỉnh sửa tính năng:
  1. Vào thư mục native-host -> nhấp đúp chạy lại "setup.bat" (để cập nhật cấu hình host).
  2. Vào chrome://extensions/ -> bấm nút "Tải lại (icon xoay tròn ↻)" tại thẻ tiện ích.
  3. Bấm F5 lại trang web đang xem để các nút nổi cập nhật phiên bản mới.

================================================================================
                           XỬ LÝ SỰ CỐ THƯỜNG GẶP
================================================================================

1. Báo lỗi "Chưa cài trình hỗ trợ — chạy native-host\setup.bat":
   -> Nguyên nhân: Bạn chưa chạy file setup.bat hoặc vừa chuyển thư mục dự án sang ổ đĩa khác.
   -> Cách xử lý: Vào thư mục native-host và nhấp đúp vào setup.bat.

2. Báo lỗi "Trình hỗ trợ dừng đột ngột":
   -> Nguyên nhân: PowerShell trên máy bị xung đột bảng mã ký tự hoặc thiếu tool.
   -> Cách xử lý: Phiên bản mới đã xử lý triệt để mã hoá UTF-8 BOM. Bạn hãy chạy lại setup.bat một lần nữa. File nhật ký lỗi được lưu tại: %TEMP%\dvi-native-host.log

3. Rê chuột không thấy nút nổi hiện lên:
   -> Bấm phím F5 để tải lại trang web (đặc biệt khi vừa cài đặt hoặc bật lại extension).
   -> Đảm bảo hình ảnh/video có kích thước lớn hơn 60x60 pixel.

================================================================================
           HƯỚNG DẪN CÀI ĐẶT ỨNG DỤNG ANDROID MOBILE NATIVE (.APK)
================================================================================

Ứng dụng Android chạy 100% độc lập trong điện thoại (không cần máy chủ, không phụ thuộc bên ngoài):
1. ĐÓNG GÓI FILE .APK:
   - Cách 1: Vào thư mục android-app và chạy file build-apk.bat.
   - Cách 2: Mở Android Studio -> Chọn Open -> Chọn thư mục android-app -> Chờ đồng bộ -> Chọn Menu Build > Build Bundle(s) / APK(s) > Build APK(s).
2. CÀI ĐẶT VÀO ĐIỆN THOẠI:
   - Gửi file .apk vào điện thoại qua Zalo (gửi dạng File), Google Drive, hoặc cắm cáp USB chép trực tiếp vào máy.
   - Trên điện thoại, nhấp vào file .apk và chọn Cài đặt (nếu máy hỏi quyền 'Cài đặt ứng dụng không rõ nguồn gốc', chọn Cho phép).
3. SỬ DỤNG TRÊN ĐIỆN THOẠI (TRÌNH DUYỆT CHUẨN GOOGLE CHROME):
   - Mở ứng dụng 'Download Video', bạn sẽ thấy giao diện chuẩn Google Chrome di động:
     + Trang Thẻ Mới (New Tab): Logo Google nhiều màu, thanh tìm kiếm lớn ở giữa, lưới icon tròn (YouTube, FB, TikTok, Insta, Threads, X, Phim, Google).
     + Thanh Omnibox trên cùng: Bo tròn kiểu viên thuốc, hiện ổ khoá 🔒 và tên miền, gõ từ khoá tìm kiếm hoặc dán URL trực tiếp.
     + Nút Đa Thẻ [ N ]: Chạm vào ô số thẻ để mở danh sách thẻ dạng lưới thu nhỏ, mở thêm thẻ mới (+), đóng thẻ (✕).
     + Menu 3 chấm ⋮: Mở Thẻ mới, Tải lại, Trang web cho máy tính (Desktop Site), Tệp đã tải xuống, Xoá dữ liệu duyệt web.
     + Mục 'Tệp đã tải xuống': Xem lại danh sách video/nhạc/ảnh đã tải, chạm mở phát ngay, chia sẻ qua Zalo/Drive hoặc xoá tệp.
   - Khi video phát, nút nổi cảm ứng [⬇ Tải về] sẽ xuất hiện trên video và nút FAB ở góc dưới màn hình sẽ sáng lên kèm số lượng media phát hiện.
   - Chọn [⬇ Tải tương thích], [MAX 2K/4K] hoặc [MP3]. Video sẽ tải ngầm và xuất hiện ngay trong Thư viện ảnh / Bộ sưu tập của điện thoại.
